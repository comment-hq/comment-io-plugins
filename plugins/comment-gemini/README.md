# Comment.io for Gemini CLI

This extension points to the current public remote MCP endpoint `https://comment.io/mcp` to work with people on shared files, documents, and structured data through one `run` tool. Authenticated tool use has been verified through official Gemini CLI 0.63.0 shipped-core components, but not through the full interactive CLI.

[Comment.io's authentication contract](https://comment.io/auth.md) now offers dynamic client registration (DCR) for public clients and HTTPS Client ID Metadata Documents (CIMD), with no scopes or client secret. Current Gemini CLI source can discover DCR after an MCP 401 and retain its ID for token refresh. Explicit `/mcp auth comment-io` can also use DCR; with a configured CIMD `clientId`, that explicit path skips DCR while the automatic 401 path may not preserve that ID. Registration grants no workspace access: a human must approve an agent in the browser.

The gallery requires a public GitHub repository, the `gemini-cli-extension` topic, and `gemini-extension.json` at the **absolute root** of the repository or release archive. This package is in a subdirectory, so the repository root alone does not meet the manifest requirement; a release-root archive can. After committing the package, run `bash plugins/comment-gemini/package-release.sh comment-gemini.tar.gz` from the repository root. It archives the committed Gemini files at the archive root without the other plugins. Inspect and test that archive before any release or topic change. Publishing a release and enabling gallery discovery are separate steps; local archive validation alone does not establish either.

## Evidence and compatibility gate

Observed on October 9, 2026: an unauthenticated MCP `initialize` POST returned HTTP 401 with resource metadata; the authorization-server metadata advertised CIMD and `registration_endpoint: https://comment.io/oauth/register`. Gemini CLI 0.63.0 installed this directory and, separately, an extracted archive with the manifest at its root in isolated homes; `extensions list` showed the context file and `comment-io` MCP configuration. These installation checks do not prove GitHub Release discovery.

On October 11, 2026, an approved test using official Gemini CLI 0.63.0 shipped-core components completed native OAuth, discovered exactly one `run` tool, and passed read-only `run name` (including a check of the designated fixture identity) and `run help`. This is component-level coverage, not a full interactive CLI/model-driven session. Token refresh, revoked-access behavior, and installation from a real GitHub Release remain untested. Those additional compatibility checks are not stated gallery listing prerequisites in the [Gemini CLI release guide](https://geminicli.com/docs/extensions/releasing/); neither local installation nor this test establishes a published release or gallery listing.

See [MCP setup](https://comment.io/llms/mcp.md) and [authentication](https://comment.io/auth.md). A human workspace member chooses and approves the agent in the browser.
