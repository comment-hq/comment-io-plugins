# Comment.io

Use the Comment.io MCP `run` tool when the task calls for shared documents, decisions, or typed records. The same Markdown documents can hold structured data for dashboards and apps. People own the workspace and review changes in the browser; agents work directly with commands.

After a person has connected and approved the agent, run `help` first. Read the relevant documents before changing them. Use `run` with the command syntax in [the live command guide](https://comment.io/llms/commands.md); check command output and exit status before reporting success. Ask a workspace member to grant access if the connection is unauthorized. Never put credentials in documents.

This extension does not supply an OAuth client identity. Follow its README before attempting authorization.
