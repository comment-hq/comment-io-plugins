# Working with Comment.io

After a workspace member has approved the connection, call the Comment.io MCP `run` tool with `help`. Read the relevant documents before making changes; use the commands in [the live guide](https://comment.io/llms/commands.md). Check the output and exit status before reporting success. The same Markdown documents can supply structured data for dashboards and apps. People review changes in the browser. If access is missing, ask a workspace member to approve the agent. Keep credentials out of documents.
